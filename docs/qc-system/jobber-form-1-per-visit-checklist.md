# Jobber Job Form 1 — Per-Visit Clean Checklist

**Attach to:** every recurring clean (all sites).
**Completed by:** cleaner, on the Jobber mobile app, before leaving site.
**Time to complete:** ~90 seconds.

> In Jobber: **Settings → Job Forms → New Form**. Add each field below with the listed type. "Required" fields block submission until filled — use them to guarantee your KPI data.

---

## Header
| Field | Type | Required |
|-------|------|----------|
| Site / practice name | Short text (auto from job) | ✔ |
| Cleaner name | Short text (auto from user) | ✔ |
| Date & time | Auto (Jobber timestamp) | ✔ |

## 🔴 Red — Bathrooms & toilets
| Task | Type | Required |
|------|------|----------|
| Toilets & urinals cleaned and disinfected | Checkbox | ✔ |
| Basins, taps, mirrors cleaned | Checkbox | ✔ |
| Floors mopped with red-zone equipment only | Checkbox | ✔ |
| Consumables restocked (soap, paper, sanitiser) | Checkbox | ✔ |
| Clinical/sanitary waste emptied | Checkbox | ✔ |
| Photo — bathroom after clean | Photo | ✔ |

## 🟡 Yellow — Clinical rooms
| Task | Type | Required |
|------|------|----------|
| Exam beds / vinyl wiped with TGA disinfectant | Checkbox | ✔ |
| High-touch points wiped (see list below) | Checkbox | ✔ |
| Clinical waste & sharps area checked | Checkbox | ✔ |
| Floors cleaned with yellow-zone equipment only | Checkbox | ✔ |
| Disinfectant contact time observed | Checkbox | ✔ |
| Photo — each clinical room after clean | Photo (multiple) | ✔ |

**High-touch points (Yellow):** door handles · light switches · exam bed rails · taps · keyboards/mouse · BP cuff & equipment surfaces · chair arms · dispensers.

## 🟢 Green — General / reception
| Task | Type | Required |
|------|------|----------|
| Reception counter & EFTPOS wiped | Checkbox | ✔ |
| Waiting room seating & arms wiped | Checkbox | ✔ |
| Door hardware & switches wiped | Checkbox | ✔ |
| Floors vacuumed / mopped | Checkbox | ✔ |
| Bins emptied | Checkbox | ✔ |

## 🔵 Blue — Kitchen & food areas
| Task | Type | Required |
|------|------|----------|
| Benches & sink cleaned (food-safe product) | Checkbox | ✔ |
| Appliance exteriors wiped | Checkbox | ✔ |
| Bins emptied | Checkbox | ✔ |

## Consumables restock (drives KPI #7)
| Item | Type |
|------|------|
| Hand soap topped up | Checkbox |
| Paper towel topped up | Checkbox |
| Hand sanitiser topped up | Checkbox |
| Toilet paper topped up | Checkbox |
| Any consumable OUT / low — flag for restock | Short text |

## Close-out
| Field | Type | Required |
|-------|------|----------|
| Anything not completed + reason | Long text | — |
| Issues noticed (damage, spills, hazards) | Long text | — |
| Cleaner sign-off | Signature | ✔ |

---

### Dashboard mapping
- All ✔ checkboxes ticked → **Task completion = 100%** (KPI #5).
- Consumables section → **Consumables compliance** (KPI #7).
- Jobber GPS + submit timestamp → **Attendance / on-time** (KPI #8).
- Photos → evidence pack in the monthly client PDF.
