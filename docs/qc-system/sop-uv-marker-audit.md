# SOP — UV Gel Marker Audit

**Goal:** objectively verify that high-touch points are being *physically wiped*, not skipped. Invisible-until-UV gel is applied to a surface; if it's gone at the next check, that surface was cleaned.

## Kit (~$30)
- UV/fluorescent gel or lotion marker (e.g. "Glo Germ" gel or UV audit gel)
- UV torch (395nm)
- Cotton buds for application, alcohol wipes to reset

## Where to place markers
Focus on the high-touch points that matter clinically. Rotate points so the team can't "learn the spots":
- 🟡 Yellow: exam room door handle, light switch, exam bed rail, cabinet handle
- 🔴 Red: bathroom tap, flush button, door handle
- 🟢 Green: reception counter edge, waiting-room chair arm, entry door push plate

Place **3–6 markers per site**, discreetly, at the end of a visit. Log where (privately — don't tell the cleaning team the exact spots).

## Procedure
1. **Apply** — small dot of gel on each chosen point after a clean. Note locations in your private log.
2. **Wait** — leave for the next scheduled clean cycle (typically the next visit).
3. **Check** — before the room is re-cleaned that day, shine the UV torch on each marked point in a dimmed room.
   - **Gone / smeared away = PASS** (surface was wiped).
   - **Still intact = FAIL** (surface was not cleaned).
4. **Record** — enter Pass/Fail per point in **Job Form 3 → UV marker audit**.
5. **Act** — any Fail: re-clean that point immediately and raise a corrective action. Repeat fails at the same point → retrain or escalate to the contractor.
6. **Reset** — wipe off residual gel with alcohol before re-marking.

## Frequency
- Yellow-heavy clinical sites: **weekly**.
- Standard sites: **monthly**, rotating which points are marked.

## Target
- **UV pass rate ≥ 90%** (KPI #3). Below that = coaching conversation with the supervisor.

## Notes
- Never place gel where it could contaminate a clinical/food surface a patient contacts before cleaning — use the *edge* of counters, the *underside* of handles.
- Photograph a Fail under UV for the client report — it's powerful proof you audit rigorously.
